# ignmartinezt.github.io

CV / portafolio personal de Ignacio Martinez. React + Vite + Tailwind CSS, publicado con GitHub Pages desde la carpeta `docs/`.

## Comandos

- `npm install` instala dependencias
- `npm run dev` servidor de desarrollo
- `npm run build` genera el sitio en `docs/` (lo que publica GitHub Pages)
- `npm run lint` revisa el código

`legacy/` guarda la versión anterior en HTML puro.
